# Algorithms | Avito Academy

ФИНАЛЬНЫЙ ФАЙЛ с решением 6D.py

Репозиторий с решениями алгоритмических задач в рамках обучения в **Avito Academy**.

**Язык:** Python 3.13.2

## 📚 Содержание

| Файл | Описание |
|---|---|
| `6A.py` | Бинарное дерево поиска (BST): вставка, удаление, поиск и обход |
| `6B.py` | BST: левые и правые повороты |
| `6C.py` | AVL-дерево: вставка и автоматическая балансировка |
| `6D.py` | ФИНАЛЬНЫЙ AVL-дерево: вставка, удаление и поиск соседних ключей |

## ⚙️ Реализованные алгоритмы

- Бинарные деревья поиска (BST)
- Повороты
- Самобалансирующиеся AVL-деревья
- Рекурсивные алгоритмы вставки и удаления
- Поиск элементов, вычисление высоты и обход деревьев

## 🚀 Запуск

Для запуска любого решения:

`python 6D.py`

Программы используют стандартный ввод и вывод. Сторонние библиотеки не требуются.
